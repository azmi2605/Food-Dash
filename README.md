# 🍔 FoodDash - Modern Food Delivery App

FoodDash is a premium, high-performance food delivery mobile application built with **Kotlin** and **Jetpack Compose**. It features a stunning dark-themed UI, smooth animations, and a robust multi-step checkout experience.

## ✨ Key Features

- **Dynamic Home Dashboard**: Browse food by categories (Burgers, Pizza, Sushi, etc.) with real-time filtering.
- **Interactive Cart**: Manage items easily with a dedicated cart screen and live total calculations.
- **Multi-Step Checkout**: 
    - **Step 1: Review**: Check items, delivery address, and payment method.
    - **Step 2: Confirm Payment**: Final summary before placing the order.
    - **Step 3: Success**: Beautiful order confirmation screen.
- **Address Management**: Edit and save delivery addresses directly within the checkout flow.
- **Payment Options**: Choose between Online Payment or Cash on Delivery (COD).
- **Responsive Design**: Fully optimized for various screen sizes with modern Material 3 components.
- **Dark Mode Aesthetics**: Sleek glassmorphism and vibrant accent colors for a premium feel.

## 🛠️ Tech Stack

- **Language**: Kotlin
- **UI Framework**: Jetpack Compose
- **Design System**: Material 3
- **Architecture**: MVVM (Model-View-ViewModel)
- **State Management**: StateFlow & collectAsStateWithLifecycle
- **Navigation**: Compose Navigation
- **Styling**: Vanilla CSS-in-Compose with custom color palettes.

## 🚀 Getting Started

1. **Clone the repository**:
   ```bash
   git clone https://github.com/azmi2605/Food_Dash.git
   ```
2. **Open in Android Studio**:
   Open the folder and wait for Gradle to sync.
3. **Run the app**:
   Select an emulator or physical device and click the **Run** button.
